Interactive surfaces and volume rendering
===========================================

Download the :download:`example bundle <downloads/postgkyl-examples.zip>`
and run from the extracted directory. The small synthetic data files are
generated by ``tests/generate_test_data.py`` and already included in the bundle.
All coordinates and scalar amplitudes in these examples are dimensionless.

These examples now have individual pages under :doc:`examples`.
