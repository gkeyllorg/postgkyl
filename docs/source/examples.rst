Examples
========

Each example has its own page with a complete Python script, the equivalent
``pgkyl`` commands, and their generated results.

Install Postgkyl using :doc:`installation`, then download and unzip the
:download:`example bundle <downloads/postgkyl-examples.zip>`.
Run the scripts and commands from the extracted directory so their data paths
resolve correctly.
